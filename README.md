# Web-Development
Layouts using HTML, CSS, JAVASCRIPT, BOOTSTRAP, jQUERY

The following layouts have been created using the basics of webdevelopment-
### Project Files:
*   **LayOut01.html / .css**: Basic HTML structure and CSS styling.
*   **layOut02.html / .css**: Interactive form and a responsive design.
*   **layOut03.html**: Implementation of the **Bootstrap 5 Framework** for optimized grid alignment and device responsiveness
*   **layOut04.html / .css (DOM Manipulation & Interaction)**: Interactive layout usin Vanilla JavaScript and jQuery. Polished **UI/UX** with custom button states, hover effects, and specialized cursors for better interactivity
